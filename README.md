# Discord Login UI Demo

A responsive, static HTML/CSS recreation of a Discord-inspired login screen with a floating music player.

## Run it

Open `index.html` in a modern browser. The audio, cover art, and playlist data are stored locally in this folder. Use the top-right player bubble to start a song, open the playlist, skip tracks, seek, and adjust volume. Browsers require a click to start audio.

## Music library

The playlist includes the 52 supplied `.opus` files. Original album covers were matched from Apple’s iTunes Search API, with the supplied image used for Malcolm Todd’s “Earrings.” “Fantasize” by Underground uses the cover shown on its Spotify track listing. The expanded player links to each song’s catalog page.

## Notes

This is a visual demo only. The login form does not submit, store, or transmit data. The QR graphic is decorative and cannot be scanned.
